# BorrowBuddy (Buddy) 🤝

> **Borrow instead of buy.** A high-craft student community borrowing platform built with React 18, TypeScript, Tailwind CSS, and Vite.

---

## ✨ Features

- **🎓 Campus-Centric Borrowing**: Filter items by campus location (Main Library, Science Building, Student Residence Hall, Engineering Block, Student Union, Campus Sports Centre).
- **📦 100+ Catalog Items**:
  - **UPSC & Civil Services Standard Textbooks** (Laxmikanth Indian Polity, Spectrum Modern History, Nitin Singhania Art & Culture, GC Leong Geography, Mrunal Patel 29-Year Solved Papers, Shankar IAS Environment).
  - **General Knowledge & Yearbooks** (Manorama Yearbook 2025, Lucent's GK, Oxford Student Atlas).
  - **Newspaper & Editorial Compendiums** (The Hindu 12-Month Editorials, Indian Express Explained, Yojana Archive).
  - **Encyclopedias & Handbooks** (Encyclopaedia Britannica, DK World History, Oxford Medical Dictionary, CRC Chemistry & Physics).
  - **Computing & Electronics** (MacBook Air, ThinkPad, Dell XPS, Anker 140W Power Banks, Apple iPad with Pencil, Kindle Paperwhite, Sony WH-1000XM4 ANC Headphones, Zoom H1n Audio Recorder, ASUS ZenScreen, Arduino Mega & Raspberry Pi kits, SanDisk & Samsung SSD Pen Drives, USB-C to USB-C Fast Charging Cables, Keychron Mechanical Keyboards, Logitech MX Master 3S Mouse, 4K Webcams, AirPods Pro).
  - **Academic & Dorm Essentials** (Lab coats, scientific calculators, sports gear, kitchen essentials, umbrellas, tools, decor).
- **🎨 Bespoke Vector Artwork Engine**: Deterministic SVG vector illustrations tailored for every item category and electronic archetype.
- **🛡️ Community Trust & Safety**: Real-time multi-factor trust score breakdown (on-time returns, verified university emails, condition ratings, completed loans).
- **⏱️ Live Loan Lifecycle**: Due reminders, borrowing request workflows, return confirmation animations, and student lender profiles.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/saivenkatkorada18/Buddy.git

# Navigate to project directory
cd Buddy

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build

```bash
npm run build
```
